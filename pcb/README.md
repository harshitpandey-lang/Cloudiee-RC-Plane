# PCB

This project does not contain a custom PCB. Standard RC electronics are used.

All electronics are connected using commercially available RC components:
- **FlySky Receiver** - Signal receiver
- **SimonK 30A ESC** - Electronic Speed Controller
- **A2212 1400KV Motor** - Brushless motor
- **9g Servos** - Control surface actuators
- **LiPo Battery** - Power source
- **XT60 Connectors** - Power distribution

These components are soldered together with wire connections. No custom circuit board design was required.

For future iterations, a custom PCB could integrate voltage regulation, telemetry, and sensor management.
