# Hardware

## Overview

This directory contains all hardware-related documentation and resources for the Cloudiee RC Plane project.

## Structure

- **bom.md** - Bill of Materials with component details, costs, and sources
- **bom.csv** - Bill of Materials in CSV format for easy importing
- **designs.md** - Design documentation with circuit and airframe design images
- **circuit-design.md** - Detailed circuit wiring and electronics notes
- **cad/** - CAD files and 3D models (currently none)

## Quick Links

- See [Bill of Materials (bom.md)](./bom.md) for component specifications
- Review [Circuit Design](./circuit-design.md) for wiring diagrams
- Check [Design Documentation](./designs.md) for airframe and spare parts

## Components Summary

- **Motor:** A2212 1400KV Brushless Motor
- **ESC:** SimonK 30A
- **Battery:** ABSD 2200mAh LiPo
- **Radio System:** FlySky FS-i6
- **Airframe Materials:** Sunboard and Depron sheets

For more details, see the [main README](../README.md).
