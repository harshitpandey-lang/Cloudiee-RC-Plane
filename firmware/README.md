# Firmware

This project does not contain custom firmware. The aircraft uses commercial RC hardware including a FlySky receiver and SimonK ESC.

All flight control and communication is handled by:
- **FlySky FS-i6 Transmitter** - Radio control system
- **FlySky Receiver** - Signal reception and servo control
- **SimonK ESC** - Motor speed control via ESC firmware

No custom code or firmware modifications were required for this build.
